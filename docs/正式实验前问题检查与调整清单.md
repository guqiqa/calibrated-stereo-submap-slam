## 必查条目

### 1. 研究边界

- [ ] 主问题仍是：固定候选预算下，可靠性门控 P 是否比 C1/C4 减少错误子地图调用并维持连续定位。
- [ ] 纯双目、70 mm 基线、640x480、15 Hz 保持不变。
- [ ] `/sim/odom` 只用于运动控制、离线真值标签和 ATE/RPE，不进入在线排序、拓扑先验、切换或可靠性估计。
- [ ] 不把活动地图工作集减少表述为总内存减少。
- [ ] 不把 pilot 或历史 45/60/90/120 m 结果表述为 P 的校准证据。
- [ ] IMU、轮速计、动态语义和外部深度传感器不进入本轮主实验。

### 2. 方法与参数一致性

- [ ] C1 只使用视觉检索和几何验证。
- [ ] C4 与 P 使用相同候选支持集、几何验证上限和确认延迟。
- [ ] 候选预算固定为 `Kv=4, Kp=3, Kg=2, K=10`，按 visual -> pose -> topology 确定性补齐。
- [ ] P 只在加载冻结校准模型后称为“可校准门控融合”。
- [ ] 固定参数写入 manifest：`submap_length=5.0 m`、`overlap=1.5 m`、几何内点 `20`、重投影误差 `3 px`、确认帧 `3`、可靠性阈值 `0.2`。
- [ ] C1/C4/P 的场景、路线、随机种子、图像和地图数据库完全一致。

### 3. 在线 ID 与离线标签

- [ ] 使用 `online_submap_id_mode=scene`。
- [ ] `runtime_submap_index -> scene_submap_id` 映射来自同一份 `submaps.json`，不得按整数下标猜测。
- [ ] 每帧记录 `scene_id`、`map_version`、`runtime_submap_ids`、`scene_submap_ids`、`candidate_ids`、`legal_submaps`。
- [ ] `candidate_covered` 只能由独立真值标签计算；标签不可用时必须同时写 `coverage_label_available=false` 和原因。
- [ ] candidate 与 legal 使用同一 scene ID 空间。
- [ ] mapping 使用 `map_database_mode=build`，query 使用独立冻结数据库的 `load`，query 不得修改地图。

### 4. mapping/query 路线协议

- [ ] 五类 query 均单独运行：normal、reverse_ring、cross_hall、cold_start、none_of_the_above。
- [ ] mapping 与 query 不复用完全相同帧序列，并保存时间标签、最近 mapping 帧、距离和视角差。
- [ ] 当前预检要求“时间 >= 5 s、空间 >= 2 m、视角 >= 30°”同时成立，但现有环形路线未满足该条件。
- [ ] 在路线重设计前，不得将失败改成通过，也不得仅修改阈值或删除失败帧。
- [ ] 路线修正后必须重新生成场景哈希、mapping 数据库和所有 query 标签。
- [ ] 若研究团队确认三项约束不应同时成立，必须在冻结协议前书面改为预注册的分层/分场景协议，并重新运行 Gate A，不得在分析脚本中隐式改变语义。

### 5. 数据质量与资源

- [ ] Gazebo 进程数为 0 或明确复用的 1 个，禁止双 `gzserver`。
- [ ] 左右图像时间戳连续，实测帧率约 15 Hz。
- [ ] 视觉里程计、状态日志、候选标签、几何验证和资源日志均非空且未截断。
- [ ] 连续 `tracking_lost` 少于 3 帧。
- [ ] 视觉/真值尺度、方向和地图坐标一致。
- [ ] 总常驻内存、活动工作集、索引内存分开记录。

### 6. 校准与统计

- [ ] 先用 development 数据拟合 `r_v/r_p/r_g`，再加载模型运行 calibration 数据。
- [ ] 再拟合 `q_cov` 和候选条件置信度模型，生成 `calibration_model.json`，阶段必须为 `confidence`。
- [ ] 测试运行期间禁止改模型、温度、阈值和候选预算。
- [ ] ECE、Brier、NLL 只在合法独立标签和冻结模型存在时计算。
- [ ] `q_cov` 与 `candidate_covered` 配对，`q_top1` 与 `top1_correct` 配对；几何失败单独统计。
- [ ] 输出风险—覆盖率曲线，并区分常规与 OOD。

## 复验顺序

1. 解决或正式修订 mapping/query 分离协议。
2. 安装并冻结拓扑生成器依赖，运行全部单元测试。
3. 生成 6 个 pilot 布局，不生成 full test 数据集。
4. 每个布局先 build 一次 mapping 数据库，再运行五类 query 和至少一个障碍变体。
5. 运行数据完整性与坐标尺度检查。
6. 拟合 reliability 阶段模型，加载模型重跑 calibration。
7. 拟合 confidence 阶段模型并冻结版本。
8. 重新运行 Gate A-C；全部通过后才允许生成和冻结 test 集。

## 当前禁止事项

- 禁止直接运行 full test 或正式 calibration/test campaign。
- 禁止用当前单布局 normal-query smoke 代替 6 布局 pilot。
- 禁止将 `null` 覆盖率解释为覆盖率为零。
- 禁止把未拟合的启发式可靠性输出写成校准概率。
- 禁止在路线分离失败时静默放宽阈值。
