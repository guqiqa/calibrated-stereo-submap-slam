# 可校准多证据子地图检索自动化实验方案

## 1. 研究边界

本实验比较 C0、C1、C4 和 P。C0 是全局地图基线；C1 仅使用视觉检索和几何验证；
C4 使用固定权重融合；P 使用可靠性门控对数似然与显式拒绝。系统保持纯双目视觉，
70 mm 基线，640x480、15 Hz；`/sim/odom` 只用于离线标签和定位误差评测。

已有 45/60/90/120 m 数据只作为规模与基础切换预实验，不能作为 P 的概率校准证据。
旧日志缺少独立 mapping/query 标签时，覆盖率、ECE、Brier、NLL 和风险-覆盖率必须
输出 `unavailable`。

## 2. 自动化系统

统一入口为 `experiment_manager.py`，项目定义位于根目录
`config/experiment_profiles.yaml`。入口负责项目和方法选择、Gazebo 单实例检查、GUI、
仿真重置、运行采集、质量检查、基础分析及轻量归档。每种方法独立启动 SLAM 节点，
切换前停止机器人和旧节点并重置世界，禁止复用运行时地图状态。

标准命令：

```bash
python3 src/visual_slam_gazebo/scripts/experiment_manager.py \
  --project c1_c4_p_basic --scenario corridor_154m \
  --methods c0 c1 c4 p --runs 3 --gui --record --analyze --archive
```

每次运行保存状态、视觉/真值轨迹、帧诊断、地图点、候选、几何验证、拒绝原因、参数
快照、日志和 manifest。异常退出保留已写数据并将 campaign 标记为 `failed` 或
`interrupted`。归档包只复制 manifest、分析、日志和协议快照；原始大文件通过路径、
大小和 SHA-256 索引引用。

## 3. 在线协议

候选预算固定为视觉 4、位姿 3、拓扑 2、合并后最多 10。C1 禁用位姿和拓扑排序；
C4 使用 `0.50/0.30/0.20`；P 使用：

```text
L_i = r_v log p_v(i) + r_p log p_p(i) + r_g log p_g(i)
```

不可用证据必须删除。最高候选概率低于 0.50 时拒绝；所有可用证据可靠性低于 0.20
时进入重定位；几何验证要求不少于 20 个 PnP 内点且重投影误差不超过 3 px。线上只
输出候选和决策，`candidate_covered` 保持空值。

## 4. 执行阶段

### G0 自动化 smoke

运行 `script_smoke`，检查单实例 Gazebo、GUI、重置、数据落盘、分析和清理。通过条件：
状态 JSON 可解析，关键文件非空，不出现连续 3 帧失锁。

### G1 在线协议 smoke

在 10 m 和 45 m 路线上分别运行 C1/C4/P 一次。确认模式、候选来源、可靠性、几何
验证和拒绝原因字段完整。此阶段不计算校准指标。

### G2 独立标签闭环

先执行 mapping trajectory 建立异构子地图并冻结地图，再执行分类 query trajectory。
所有 query 与 mapping 分次采集且至少间隔 5 s；同向、反向、跨区、冷启动和 OOD 使用
各自预注册条件，不再要求每帧同时满足 2 m 与 30 度。离线使用真值确定合法子地图并写入
`candidate_labels.csv`。候选覆盖定义为
合法子地图是否位于候选集合，禁止从 `active_submap` 推断。

### G3 校准和冻结

按布局种子划分 12 个 development 布局、9 个 calibration 布局和 9 个测试布局。
development 用于拟合证据可靠性，calibration 用于拟合温度、coverage 模型和拒绝阈值，
然后冻结 `calibration_version`。测试布局不得再次调参。

`q_top1` 通过候选融合分数温度校准；`q_cov` 必须使用冻结的
`candidate-coverage-v1` 逻辑回归模型。后者输入候选总数、三路候选来源数量、融合峰值
与 Top-1/Top-2 间隔、三路最高分和三路证据不可用标志，共 12 维，不得再从
`q_top1` 单变量换算。

### G4 正式对比

在三类拓扑、30 个布局上比较 C0/C1/C4/P。每个测试布局执行 8 条 query trajectory，
每条重复 3 次。报告 Recall@1/3/10、几何验证成功率、错误调用率、拒绝率、重定位
成功率、ATE/RPE、切换跳变、平均/P95 时间、活动工作集和内存分类。

### G5 OOD 与规模实验

冻结版本测试遮挡、模糊、低纹理、位姿突变、丢帧、冷启动、未见纹理和错误拓扑。
另在 45/60/90/120 m 路线上报告规模变化。OOD 注入器和多布局生成器完成前，对应
profile 必须保持不可启动状态。

## 5. 统计与验收

基础分析自动生成数据质量报告、方法对比、候选/几何/拒绝表、分段统计及检索回放。
有独立标签后再生成 ECE、Brier、NLL、风险-覆盖率和 AU-RC。

正式验收要求：Recall@10 不低于 95%，切换成功率不低于 95%，无连续 3 帧以上失锁；
P 在相同候选预算、接受率和确认延迟下不劣于 C4，且 P95 时延不超过 C4 的 1.25 倍。
若只降低活动地图点，只能报告“降低活动工作集和局部验证量”，不能写成总内存下降。
