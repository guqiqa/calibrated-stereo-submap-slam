## 0. 定位与统一口径

在不引入 IMU、轮速计、外部深度传感器或 `/sim/odom` 真值的前提下，用双视觉参考与显式不可观测区间管理，避免转弯视觉退化期间的不可靠位姿先验污染子地图检索与切换决策。

论文与工程口径统一为：

> **纯视觉 VO + 显式可观测性状态管理**（不再笼统写作「纯 VO」）。

本方案**不声称**恢复不可观测区间内的逐帧真实转角；它要做的是让系统准确知道自己「不知道」，并安全地拒绝、延迟与重获定位。这与本文「可拒绝」「证据可靠性门控」的主线一致。

## 1. 问题依据（实测，单次运行）

数据：`experiments/vo_multi_turn_yaw_slow_010_first_turn_20261016/c0/run_01`（原地旋转，指令角速度 `0.1 rad/s`，目标 180°，运行在 16.7 m 处提前结束）。
对齐文件：`frame_diagnostics.csv`、`visual_odom.csv`、`trajectory_truth.csv`、`control_diagnostics.csv`。

| 阶段 | 真值 yaw | 视觉记账 yaw | 差 |
| --- | ---: | ---: | ---: |
| t+173→220 s（前 47°） | 67.64° | 71.14° | **+3.50°（过转）** |
| t+220→244 s（空窗 24 s） | +29.90° | +10.47° | **-19.43°（丢弃）** |
| t+244→结束 | +23.73° | +24.12° | +0.39° |
| 全程 | 124.59° | 108.24° | **-16.35°** |

空窗特征：173 帧 `temporal_matches_2d < 10`，123 帧估计器 `unavailable`；第 1 次 `rebootstrap` 恰好发生在空窗结束处。

同一份数据用 `tools/turn_attribution.py` 复算（区间级记账，只读；输出 JSON / Markdown / 时间线 PNG）：

| 项 | 数值 |
| --- | ---: |
| 真值累计 yaw | 124.59° |
| 视觉累计 yaw（visual_odom.csv） | 108.24° |
| 净差 | -16.35° |
| 应用增量区间 | 397 段 |
| 该区间累计应用 / 真值转角 | 108.90° / 104.08° |
| 估计器过转 | +4.82° |
| 参考重置丢弃次数 / 丢弃真值转角 | 3 / 20.51° |
| 空窗帧数 / 时长 | 173 帧 / 24.0 s |
| 空窗内真值 / 视觉记账 | 29.84° / 10.47° |

按 `state | decision` 的真值转角（前四项）：`rotation_only | accepted_rotation_increment` 84.42°、`rotation_waiting | temporal_match_failure` 19.88°、`rotation_settling | rotation_settling` 10.74°、`rotation_only | accepted_descriptor_rotation` 5.55°。

结论：

1. 主要损失不是「估不准」，而是**整段区间被丢弃**，且失败帧会**静默前移参考系**（位姿不动、参考前移）；
2. 次要损失是约 5% 的**估计正偏置**（与 `rotation_scale_factor=1.06`、`rotation_wahba_negative_scale=1.043` 同量级）；
3. 转弯是 `0.1 rad/s` 慢速原地旋转，**不是运动过快或模糊导致的无解场景**，因此本方案的重点是状态管理而非提高匹配能力。

## 2. 三态定义

| 状态 | 含义 | 在线输出 |
| --- | --- | --- |
| `OBSERVED` | 当前帧相对当前可信参考 `R_cur` 存在合格视觉几何约束 | 位姿作为**有效视觉测量**，可用于 `p_p`、`r_p` 与切换确认 |
| `UNOBSERVED` | 连续 `f_enter` 帧相对 `R_cur` 不再满足合格约束 | 位姿**不作为有效视觉测量**；仅作预测维持，并显式标记 |
| `REACQUIRED` | 已建立新的可信参考 `R_post`，并通过连续 `f_exit` 帧确认 | 恢复为有效测量；区间开始闭合结算 |

迁移规则：

```text
OBSERVED  --(连续 f_enter 帧不合格)-->  UNOBSERVED   [冻结 R_pre = R_cur，开区间]
UNOBSERVED --(对候选参考合格，连续 f_exit 帧确认)--> REACQUIRED  [确定 R_post]
REACQUIRED --(区间闭合结算完成)--> OBSERVED
UNOBSERVED --(超过重获时限仍未通过)--> UNOBSERVED + 全局重定位请求
```

进入与退出使用**两套不同阈值**与**两个不同计数器**，避免状态抖动。

## 3. 双参考定义

| 名称 | 定义 | 生命周期 |
| --- | --- | --- |
| `R_track` | 逐帧短基线参考（上一帧） | 每帧更新；仅用于增量测量 |
| `R_pre` | 进入 `UNOBSERVED` 前最后一个通过几何验证的可信参考 | 进入时冻结，区间闭合后释放 |
| `R_post` | 离开 `UNOBSERVED` 后第一个重新通过几何验证并连续确认的参考 | 重获时建立，仅在重获之后被后续帧使用 |
| `R_cur` | 当前权威可信参考，取 `R_pre` 或 `R_post` 中较新者 | 由状态机维护 |

语义要点：

- `R_pre` 是「最后可信的过去」，`R_post` 是「重新可信的现在」，两者之间是被显式标记的空窗；
- 空窗内的相对约束**不足以支撑视觉测量**，因此不作为测量输出；
- 区间闭合给出 `R_pre -> R_post` 的几何闭合误差，作为可观性退化代价的度量。

## 4. 可观测性判据（结构冻结）

判据必须由**多类证据共同决定**，禁止仅用「特征点少于某阈值」判定。所有量均为「当前帧相对候选参考帧」的量。

| 证据 | 进入 `OBSERVED` 的条件 | 触发 `UNOBSERVED` 的条件 | 已冻结阈值（2026-10-16，T1 后维持现值） |
| --- | --- | --- | --- |
| 有效点（双目点或时序匹配数） | `>= N_ok` | `< N_enter` | `N_ok = 30`，`N_enter = 15` |
| 几何内点数 | `>= n_ok` | `< n_enter` | `n_ok = 20`，`n_enter = 10` |
| 内点率 | `>= rho_ok` | `< rho_enter` | `rho_ok = 0.45`，`rho_enter = 0.25` |
| 重投影 RMSE | `<= e_ok` | `> e_enter` | `e_ok = 2.0 px`，`e_enter = 3.0 px` |
| 相对参考帧视角变化 | `<= theta_ok` | `> theta_enter` | `theta_ok = 15°`，`theta_enter = 20°` |
| 特征空间分布（3x3 网格覆盖格数） | `>= g_ok` | `< g_enter` | `g_ok = 5`，`g_enter = 3` |
| 几何条件数（平面 3 自由度法方程） | `<= kappa_ok` | `> kappa_enter` | `kappa_ok = 1e3`，`kappa_enter = 1e4` |
| 连续不合格帧数 | — | `>= f_enter` | `f_enter = 2` |
| 相对 `R_post` 连续合格帧数 | `>= f_exit` | — | `f_exit = 3` |

补充规则：

- 视角变化必须参与判据：参考帧过期本身就意味着相对约束失效；
- 阈值允许在上限内与既有参数对齐（`min_3d3d_inliers=10`、`min_pnp_inliers=10`、`switch_max_reprojection_px=3.0`、`min_stereo_points=35`），但不得直接复用单一参数作为状态判据；
- 判据数值在 T1 开发数据上确定后写入配置并**停调**；测试期间禁止修改。

## 5. 区间记账与不变式

每个 `UNOBSERVED` 区间必须产生一条记录：

| 字段 | 含义 |
| --- | --- |
| `interval_id` | 自增编号 |
| `start_frame` / `end_frame` | 起止帧号（帧号与时间戳同时记录） |
| `enter_reason` | 触发进入的证据与数值快照 |
| `r_pre_frame` / `r_post_frame` | 两端可信参考 |
| `closed_by` | `increment_bridge` / `anchor_validation` / `relocalization` / `still_open` |

闭合原因的含义与判定顺序（实现见 `stereo_vo_sim.cpp` 的重获处理）：

1. `anchor_validation`：由 `R_pre` 与 `R_post` 之间的描述子 + Wahba 桥接给出旋转闭合；
2. `relocalization`：地图关键帧 PnP 给出独立绝对位姿，且位姿跳变在 `rotation_relocalization_max_pose_jump_m` 内；
3. `increment_bridge`：无独立绝对参考（例如 180° 反向视野无法与正向建图关键帧匹配），但区间内短基线链连续（≥90% 帧有合格增量）——显式以增量桥接闭合，闭合误差记为**不可独立测量**；
4. `still_open`：以上都不成立，保持未闭合，并继续按 `relocalization_search_period` 搜索绝对参考。

判定顺序保证：能用独立几何验证就不用桥接，不能用就显式说明，不允许静默挂起。
| `reacquire_frames` | 重获耗时 |
| `closure_translation_m` / `closure_rotation_deg` | `R_pre -> R_post` 闭合误差 |
| `measurements_suppressed` | 区间内被抑制的伪测量帧数 |

不变式（实现必须保证，单测覆盖）：

- **I1**：位姿未被更新的帧，**不得**移动 `R_pre`，也不得静默重置参考系；
- **I2**：每个区间要么闭合（`closed_by` 非空），要么显式保持 `still_open` 并触发全局重定位条件；不允许「无声消失」；
- **I3**：在线任何决策只允许读取产生于当前帧或更早帧的信息，`R_post` 仅在重获之后参与；
- **I4**：离线回填结果只写入独立产物，不得写入在线状态文件或在线评测输入；
- **I5**：区间内位姿不作为有效视觉测量进入 `p_p` / `r_p` / 切换确认；轨迹插值只用于显示。

## 6. 反信息泄漏硬约束

- `R_post` 只能在转弯之后获得，在线 `UNOBSERVED` 阶段不得提前使用；
- 禁止用常速度插值、轨迹平滑或后验优化结果冒充视觉测量；
- 使用 `R_pre` 与 `R_post` 做离线区间优化（B3）时，必须单独报告，且不得用于证明在线切换正确；
- 若 `R_pre` 与 `R_post` 分属不同子地图，其联系必须通过**独立几何验证**建立，不得只靠拓扑或索引推断；
- 评测脚本必须记录 `backfill_used = false` 才可计入在线主结果。

## 7. 在线行为（UNOBSERVED 期间）

- `p_p`（位姿似然）标记为 `unavailable`；
- `r_p` 随「距最近一次有效视觉测量的帧龄」快速衰减（候选形式：`r_p = r_p_last * exp(-age / tau_rp)`，`tau_rp` 待 T1 冻结），并与既有 `retrieval_low_reliability = 0.20` 的语义衔接；
- 视觉检索 `p_v` 仍可运行，但每个候选与最终决策必须标注是否通过几何验证；
- 子地图切换：拒绝或延迟确认，必要时触发全局重定位；不得以预测位姿强行确认切换；
- 状态日志必须逐帧写出可观测性字段（见第 10 节），保证离线可审计。

## 12. 实施顺序与阶段门

| 阶段 | 内容 | 通过条件 |
| --- | --- | --- |
| T0 | 离线归因工具 + 基线时间线 | 能在任意历史运行上复现第 1 节数字 |

## 13. 变更与冻结流程

1. 本文件先冻结判据结构与不变式；数值经 T1 确定后写入配置并停调；
2. 任何判据或阈值变更都必须新增版本段落并注明日期与依据，不得原地覆盖历史值；
3. T2 与 T5 通过后，按 `docs/研究状态与冻结边界.md` 第 5 节流程打标签并推送 `backup`；
4. 冻结后修改任何判据，视为开启新的开发轮次，需要重新划分开发 / 验证 / 测试数据。

### 旋转提交策略：短窗口一致性（2026-10-16）

单帧旋转**永不单独提交**（避免把未确认的旋转伪装成连续位姿）。提交条件：

1. 单帧旋转绝对值 ≥ `obs_rotation_min_frame_deg = 0.05°`；
2. 质量门通过（`pure_rotation_model`，或三路估计器之一可信）；
3. 与上一候选帧**同号**；
4. 窗口累计绝对角度 ≥ `obs_rotation_commit_deg = 0.20°`，窗口帧数 ≥ `obs_rotation_commit_frames = 2`。

只有满足条件的**当前帧**才提交；未确认帧记为 `candidate`，**不改写已发布位姿**，也不做事后补偿。提交后窗口清零，不形成无界累积。状态字段：`rotation_candidate_frames`、`rotation_commit_frames`、`rotation_commit_sign`、`rotation_commit_abs_deg`、`rotation_commit_pending_deg`、`rotation_commit_reason`。

`rotation_wait_rebootstrap_frames` 同时降级为**日志/超时指标**，不再参与：当前旋转是否接受、是否启用 local fallback、是否建立新参考、是否进入 `validating`。

同一轮改动还包含：状态机推进从 `publish_status()` 移出、在每个路径的几何估计完成后立即更新，并且 `UNOBSERVED` 帧不再参与子地图评估与关键帧写入；重定位被拒绝时不再重建参考（保持 `rotation_gap_hold`）；闭合原因按来源分类（PnP → `relocalization`，描述子/Wahba → `anchor_validation`，连续短基线 → `increment_bridge`，否则 `still_open`）。
### 全局提交门控的尝试与回退（2026-10-17）

必须同时说明它由 `measured_internal` 驱动。

#### −12.5° 缺口的归因（逐状态）

同一次运行按 `state` 分解真值转角与内部 measured 转角：

| state | frames | 真值转角 | 内部 measured | 比例 |

| `rotation_waiting` | 95 | 20.25° | 0.00° | **0.0%** |

| 其它（settling / rebootstrap / init） | 4 | 0.00° | 0.00° | — |

三点规律（三次运行一致）：

1. 缺口**几乎全部**来自 `rotation_waiting`：20.25° 真值转角被记为 0，整段丢弃；
2. `rotation_only` 反而**过转 5.2%**，与 `rotation_scale_factor=1.06`、
   `rotation_wahba_negative_scale=1.043` 同量级，指向标定过补偿；
3. 若仅补齐 `rotation_waiting` 而不动尺度，总和会过冲到约 184°，即两项误差当前是
   **相互抵消**，不能把 −12.5° 当成"估计器整体偏低"。

因此下一步的长基线绝对航向候选源，目标应是**覆盖 `rotation_waiting` 帧**，

| --- | ---: | ---: | ---: | ---: | ---: |

结论：

1. **帧率不是精度旋钮，而是会改变系统定性行为的隐藏变量**。不能指望"提高帧率"收窄
   −12.5°，也不能把当前 −12.5° 单独归因于几何模型；
2. 既有全部结果（含本分支所有运行）都在 5.85 fps 下取得，必须在论文系统条件中声明；
3. 图像 QoS 是真实缺陷（56% 帧被静默丢弃），但修复前必须先解释 `tracking` 状态在

4. 该开关以 `image_qos_reliable` 参数暴露，**默认 false**，不改变既有可比性；
5. 新增帧计数 `processed_frames`、`queue_trim_drops`、`pair_sync_rejects`、
   `queue_left/right`、`sync_reject_delta_ms`，使"处理率"可被审计而不是推断。

### 米制路径旋转符号的定位（2026-10-18，reliable 15 Hz）

在同一参考窗口内（`reference_age_frames` 连续递增，参考位姿保持不变）逐帧对照三类增量：

| `motion_source` | n | ΣdTruth | ΣdSelected | ΣdInternal | ΣdPnP | ΣdRigid |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| `pnp_stereo_consistent` | 560 | +35.52° | +36.12° | **−36.12°** | +36.12° | +14.56° |
| `pnp_quantized_3d3d` | 1517 | +0.14° | −0.12° | +0.12° | −0.12° | +1.29° |

读法：

1. **估计器是对的**：PnP 与 3D-3D 的 yaw 增量都与真值同号；
2. `selected_transform` 的 yaw 增量等于 PnP 的 yaw 增量（+36.12°），与真值同号同幅；
3. `compose_world_pose_from_current_T_previous(reference_world_pose_, selected_transform)`
   输出 **−36.12°**，恰好取反；
4. **平移没有被取反**：导出到 Gazebo 系的 `trajectory_visual.csv` 从 x=0.08 走到 x=16.48
   （真值 16.72），前进正确。

因此这不是"整体求逆"——那是会连平移一起反的。观察到的是**旋转与平移的约定不一致**。
刚体变换下两者必须同向，所以最可能的机制是：`points3d` 的存储约定（y 向上）与针孔投影
模型（y 向下）不一致，使 solvePnP 求出的 R 被 `diag(1,−1,1)` 共轭、yaw 符号翻转，而 t 主要
由 z 分量主导、看起来仍然正确；`constrain_optical_pose_to_ground_plane` 再把这个翻转吸收
进最终朝向，于是只有 yaw 受影响。

**下一步只做一件：合成点集单测，不再用仿真试错。**

```text
1) y 向下的针孔模型生成 3D 点 -> 投影 -> solvePnPRansac
   断言回收的 current_T_reference 的 yaw == +delta
2) 同一组点把 y 取反（y 向上）重复
   预期回收的 yaw == -delta  (即 diag(1,-1,1) 共轭机制成立)
3) 断言 heading(compose(A,B)) 的符号语义:
   B 为 ref_T_current 时应为 +heading(B)，为 current_T_ref 时应为 -heading(B)
```

单测一旦建立，修复点就是唯一的：要么统一 `points3d` 的 y 约定，要么在组合前对
`selected_transform` 的旋转做共轭校正。**在单测给出结论之前不得再改仿真主路径。**

本轮已加入的逐帧诊断字段（`status_sim`，追加）：`selected_transform_yaw_deg`、
`pnp_transform_yaw_deg`、`rigid_transform_yaw_deg`、`reference_world_yaw_deg`、
`reference_age_frames`。

#### 四层坐标约定单测（2026-10-18）与其后修正

`test/pose_convention_test.cpp`（15 项断言全通过）给出的事实：

| 层 | 结论 |
| --- | --- |
| L1 | `solvePnP` 精确回收 `current_T_reference`（yaw +5.000，t 误差 < 5 mm） |
| L2 | `compose(A,B) = A·B⁻¹`：传 `current_T_reference` → Δyaw **−5.000**、平移**前进**；传 `reference_T_current` → Δyaw **+5.000**、平移**后退** |
| L3 | 光学系 yaw **+5.000** 的姿态经 `make_gazebo_T_initial_optical` 后，Gazebo 航向为 **−5.000** |
| L4 | `S·R·S`（S=diag(1,−1,1)）行列式仍为 +1、保持正交，**yaw 幅值不变**（本例 +5.000 → +5.000） |

由此得到的修正结论：

1. **y 反射假设不成立**：L4 表明共轭不单独翻转 yaw 的符号，只是同一幅值。上一轮把它列为
   "最可能机制"是错误的，已撤回；
2. **L2 + L3 组合说明**：光学系的航向增量与 Gazebo 真值航向增量之间存在 **−1 的约定差**，
   因此"把 `internal_pose_heading_deg` 直接与 `trajectory_truth.csv` 的 Gazebo yaw 比较"
   **本身就不成立**。上一轮据此得出的"组合后 yaw 取反"（−36.12 对 +35.52）**不能作为缺陷证据**；
3. 因此 `selected_transform_yaw_deg` 与 `dInternal` 的符号差（+36.12 对 −36.12）与
   L2/L3 完全一致，属于**约定，不是错误**；
4. 仍未解释的矛盾：历史运行中 `visual_odom` 的 yaw（`2·atan2(qy,qw)`）与 Gazebo 真值
   **同号**（124.59 vs 108.24），与 L3 的 −1 约定不符。**该矛盾必须先解决**，否则
   `-12.5°`、`-17.51°`、`-120.33°` 这些数字的符号基线都不确定。
